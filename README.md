# Proyectos de ingeniería de datos


## Proyectos

### [1_EDA/](./1_EDA/) - Análisis exploratorio de datos
![Resumen del proyecto de análisis exploratorio](./images/1_1_Project1_EDA.png)
Análisis con SQL de las tendencias del mercado laboral para ingenieros de datos, mediante consultas analíticas.

**Habilidades:** uniones complejas, agregaciones, funciones analíticas y validación de la calidad de los datos.

### [2_DW_Mart_Build/](./2_DW_Mart_Build/) - Almacén de datos y marts analíticos
![Arquitectura del flujo de datos](./images/1_2_Project2_Data_Pipeline.png)
Pipeline ETL de principio a fin que transforma archivos CSV sin procesar en un almacén de datos con esquema en estrella y crea marts para el análisis.

**Habilidades:** modelado dimensional, desarrollo de pipelines ETL, arquitectura de marts y prácticas de producción.
